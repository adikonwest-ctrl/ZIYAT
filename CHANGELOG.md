# Changelog

## [Unreleased]

### Added
- подготовлена корневая точка входа `server.ts` для zero-configuration Node.js deployment на Vercel без изменения локальной команды запуска;
- обработчик запросов экспортируется для повторного использования.

### Fixed
- административная панель и изменения контента принудительно отключены в среде Vercel, пока не подключено постоянное хранилище.

### Known limitations
- live deployment не выполнен: веб-загрузчик Vercel не принял локальную папку в доступном браузерном инструменте;
- для публикации через GitHub требуется авторизовать GitHub и создать удалённый репозиторий; сейчас проект находится только в локальном Git;
- производство пока обслуживает публичный сайт с JSON-данными из комплекта, редактирование и загрузка файлов не доступны.

## [1.1.1] - 2026-10-13

### Fixed
- удалён встроенный пароль администратора по умолчанию; вход отключён с HTTP 503, пока серверный пароль не задан через окружение;
- cookie сессии помечается `Secure` в production.

### Significant changes
- добавлен `.gitignore` для локальных секретов и артефактов платформы;
- добавлен безопасный `.env.example` без действительных учётных данных.

### Known limitations
- приложение пока хранит изменяемый контент в JSON-файлах, а сессии — в памяти процесса; Vercel не обеспечивает для этих данных постоянное хранение;
- требуется проверить развёртывание через новую корневую Node.js точку входа Vercel; на Vercel админка закрыта до перехода на постоянное хранилище;
- реальная загрузка файлов изображений через админку не реализована; изображения сейчас указываются URL.

### Significant changes
- добавлена отдельная точка входа `server.ts` для zero-configuration Node.js deployment на Vercel без переписывания локального сервера;
- обработчик веб-запросов экспортируется для повторного использования.

## [1.1.0] - 2026-10-12

### Added
- добавлена защищённая административная панель по адресу `/admin`;
- внедрено серверное авторизационное состояние через cookie-сессию и проверка прав доступа для административных API;
- добавлены операции создания, редактирования и удаления исторических объектов карты из панели администратора;
- административная панель поддерживает поиск и редактирование основных полей объекта карты, включая координаты, описание и источник.

### Fixed
- восстановлена возможность управления картой без изменения публичной архитектуры сайта;
- обновлены маршруты и данные по проекту, чтобы публичный сайт и административный интерфейс работали совместно.

### Significant changes
- выбран подход с отдельной административной частью, работающей поверх публичного одностраничного сайта;
- данные карты остаются в отдельном JSON-источнике и обновляются через серверные API, а не через прямую правку кода.

### Known limitations
- список исторических объектов остаётся ограниченным подтверждёнными точками, доступными на данном этапе;
- в проекте сохраняется минимальная серверная авторизация без отдельной базы данных и сложной роли/права, что соответствует текущему объёму и архитектуре проекта.

## [1.0.0] - 2026-10-11

### Added
- создана первая полноценная версия сайта ZIYAT как единая одностраничная платформа;
- добавлена интерактивная карта на Leaflet с OpenStreetMap и маркерами исторических объектов;
- реализованы разделы для исторических мест, личностей, энциклопедических материалов и археологического контекста;
- внедрён поиск по названию и фильтрация объектов по категориям на карте;
- подготовлена отдельная структура данных для объектов карты в `data/map-places.json`.

### Fixed
- устранена прежняя архитектура с разбросанными страницами и заменой карты на текстовые списки;
- исправлена навигация по секциям с учётом высоты фиксированной шапки.

### Significant changes
- проект переведён в одностраничный формат с последовательной подачей контента и плавной прокруткой;
- реализована более строгая политика: карта использует реальные тайлы и отдельные геокоординаты, а не демонстрационные тексты;
- сохраняется светлая музейная визуальная концепция с зелёным акцентом и пространственной композицией.

### Known limitations
- список исторических объектов пока ограничен проверенными точками, доступными на ранней стадии проекта;
- контент карты и материалов обновляется по мере появления новых подтверждённых источников и исследований.
