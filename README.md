# ZIYAT

ZIYAT — одностраничная образовательная платформа с картой исторических объектов, материалами по личности и региональной истории Актюбинской области.

## Запуск

1. Установи `ZIYAT_ADMIN_USER` и `ZIYAT_ADMIN_PASSWORD` как переменные окружения. Например, в PowerShell:
   ```powershell
   $env:ZIYAT_ADMIN_USER = "ziyat_admin"
   $env:ZIYAT_ADMIN_PASSWORD = "<длинный случайный пароль>"
   ```
   `.env.example` перечисляет нужные переменные; встроенный сервер Node.js сам файл `.env` не загружает.
2. Открой терминал в папке проекта и выполни:
   ```bash
   npm start
   ```
3. Открой в браузере:
   ```text
   http://localhost:3000
   ```

## Что включено в текущую версию

- единая одностраничная структура сайта;
- интерактивная карта на Leaflet и OpenStreetMap;
- карточки исторических объектов с фильтрацией и поиском по названию;
- разделы с историческими местами, личностями и энциклопедическими материалами;
- блок археологии и исторического контекста;
- защищённая административная панель по адресу `/admin` с серверной авторизацией и управлением объектами карты.

## Структура проекта

- `server.js` — минимальный веб-сервер на Node.js;
- `public/index.html` — главная страница и секции сайта;
- `public/app.js` — навигация, карты, фильтрация и рендер данных;
- `public/styles.css` — визуальный стиль проекта;
- `data/content.json` — общие данные сайта;
- `data/map-places.json` — данные объектов карты.

## Production: ограничения перед публикацией

- Сборки как отдельного шага у проекта нет: это минимальное приложение на Node.js без bundler и без зависимостей npm.
- Админ-панель сохраняет записи непосредственно в `data/content.json` и `data/map-places.json`; сессии находятся в памяти сервера. Это подходит для локального демонстрационного запуска, но не для Vercel/serverless и не гарантирует сохранность изменений после перезапуска или нового развёртывания.
- Для production-админки требуется постоянная база данных и адаптация API к serverless-платформе. На Vercel административный интерфейс и редактирование намеренно отключены до подключения постоянного хранилища.
- `server.ts` — входная точка Node.js для развёртывания публичного сайта на Vercel; проект использует его автоматическое обнаружение, отдельная команда сборки не требуется.
- Загрузка изображений в проекте не реализована: интерфейс принимает URL, а не файлы.
- Настрой переменные окружения `ZIYAT_ADMIN_USER` и `ZIYAT_ADMIN_PASSWORD` только на сервере/в настройках хостинга. `ZIYAT_ADMIN_PASSWORD` обязателен; встроенного пароля больше нет. `.env` исключён из Git.
- До выполнения этих работ нельзя считать production-деплой Vercel с сохранением данных готовым.
